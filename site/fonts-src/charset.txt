# Characters kept in the site fonts (scripts/make_woff2.py). The build warns
# if a page uses a character that is not in this list, because that character
# shows in a fallback font. Add a range here and run make_woff2.py again.
# One range per line: U+XXXX or U+XXXX-YYYY, then a comment.
U+0020-007E   Basic Latin
U+00A0-00FF   Latin-1: accents, degree sign, middle dot, multiplication sign
U+2010-2027   Dashes, quotation marks, bullet, ellipsis
U+2030-203A   Per mille, primes, angle quotation marks
U+2122        Trade mark sign
U+2190-2193   Arrows
U+2212        Minus sign
U+2248        Almost equal to
U+2264-2265   Less-than or equal to, greater-than or equal to
