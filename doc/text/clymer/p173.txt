1. Clean and dry all parts before assembly. Lubri-

cate all parts with engine oil.

2. Install fifth gear (Figure 11). The gear dog 
recesses must face out (away from first gear).

3. Install the thrust washer and snap ring (Figure

12). The snap ring must seat in the shaft groove.

4. Install third gear (Figure 13). The side of the 
gear with the shift fork groove must face out (away 
from first gear).

5. Install the snap ring and spline washer (Figure

14). The snap ring must seat in the shaft groove. The 
ends of the snap ring must be offset from the spline 
washer teeth.

6. Install fourth gear (Figure 15). The flat side, 
with the recesses, must face in (toward first gear).

7. Install the spline washer and snap ring (Figure

16). The snap ring must seat in the shaft groove. The 
ends of the snap ring must be offset from the spline 
washer teeth.

8. Install second gear (Figure 17). The chamfered,

inner edge of the gear must face in (toward first

gear).

9. Install the thrust washer and bearing (Figure

18).

10. Install the snap ring (Figure 19). The snap ring 
must seat in the shaft groove. The sharp edge of 
the 
snap ring must face out (away from first gear).

11. Check that all parts are secure and that the gears

spin, slide and engage freely on the shaft. Wrap and

store the assembly until it is ready to install into the 
crankcase. Install the complete transmission assem- 
bly as described in Chapter Five.
