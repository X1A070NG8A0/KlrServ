This 
technique 
is recom-

1. Clean and dry all parts before assembly. Lubri-

cate all parts with engine oil.

2. Install second gear. The side of the gear with the 
gear dog recesses must face out (away from the

splined end).

3. Install the thrust washer and snap ring. The snap 
ring must seat in the shaft groove.

4. Install fourth gear. The side of the gear with the

shift fork groove must face out (away from the 
splined end).
